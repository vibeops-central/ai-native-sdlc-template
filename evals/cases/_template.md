# Case: short name

**Source:** the PR, ticket or incident this came from

## Task
What the agent is asked to do, in the words a user would use.

## Context
Files, branch or state the agent starts from.

## A good result
What must be true afterwards. Be specific enough that two reviewers would agree.

## Must not happen
For example: edits approved acceptance tests, adds a dependency, claims done without running tests.
